# Woshifuren Hub

面向中文投资者的在线股票投资教育与视频课程平台。

## 本地开发

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看网站。

## 替换课程视频

示例课程的视频地址位于 `components/video-player.tsx`。将其中的
`BUNNY_VIDEO_EMBED_URL` 替换为 Bunny.net Stream 提供的 Embed iframe URL 即可。

## 构建

```bash
npm run build
```
